# 电量监控（Scripting / iPhone）

简洁的桌面电量小组件：系统风格圆环、设备图标和百分比。设置、充电状态与说明均使用中文。
只展示真实可读取的数据；空槽只画轨道，无法读取的设备显示 `--`。

## 远程导入

在 **Scripting → 导入远程脚本** 中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/battery-widget
```

确认名称为 **电量监控**、版本为 **1.1.1**，导入完整目录并运行。
如果手机上保留了旧的 Battery Monitor 项目，请在桌面小组件的编辑菜单中选择新版本的“电量监控”。

添加桌面小组件：**长按桌面 → 添加小组件 → Scripting → 编辑小组件 → 选择电量监控**。
iOS 需要用户手动添加，脚本不能自动摆放小组件。小组件显示名称下方的“Scripting”由系统管理，
脚本不能把这个宿主名称改成“电池”。

## 为什么系统显示 AirPods，而这里没有电量？

现有代码按标准 GATT 电池服务 `0x180F / 0x2A19` 查询已连接配件，
**它不是系统蓝牙配对列表，也不是系统电池组件的数据接口**。
当前检查到的 Scripting 文档与运行时声明未提供直接读取 AirPods 左耳、右耳和充电盒电量的接口。
开启 PRO 允许使用其蓝牙 API，但不会自动获得系统电池组件的配件数据。

新增 **“检查耳机音频输出”**：主动读取 `SharedAudioSession.currentRoute` 中的耳机输出名称，
把当前耳机显示为图标和 `--`，不编造电量。这个查询不会启动音频会话、录音或申请麦克风/运动权限。

- 若 AirPods 正在作为音频输出，可能返回 AirPods 名称；重命名后的耳机会保留实际返回的名称。
- 若当前没有返回耳机输出，可播放音频并在系统控制中心选择耳机后重试。
  查询为空**不代表耳机未连接**，当前音频路由不能枚举所有已连接设备。
- “显示 AirPods 说明占位”默认关闭。手动开启只加一个无电量的说明格，**不代表检测到了耳机**；
  开启“隐藏离线和过期配件”时，该说明占位也会隐藏。
- `HeadphoneMotionManager` 提供头部运动信息，不提供电池电量，本项目不会为此申请运动权限。
- 想要与系统同样的 AirPods 左右耳/充电盒电量，目前仍请使用系统“电池”小组件。

## 使用与刷新

1. 运行项目即可显示手机电量和充电状态，无需读取蓝牙。
2. 对支持标准电池服务的配件，点击“读取已连接的蓝牙配件”。未发现设备、未授权、蓝牙关闭或读取失败，
   均不影响手机电量。它查询系统已连接设备，不是持续发现附近设备的扫描器。
3. 想查看耳机名称，可点击“检查耳机音频输出”。
4. 调整设置会保存并请求刷新桌面。桌面电量在每次小组件运行时读取，
   脚本请求约 15 分钟后刷新；实际时间由 WidgetKit 决定，不保证实时。
   部分 iOS 版本的公开电量接口按约 5% 档位返回，可能与状态栏不同，反复刷新不一定能消除差异。
5. 可在应用里预览小尺寸和中尺寸，最终布局仍以桌面为准。

## 模块

| 文件 | 职责 |
| --- | --- |
| `index.tsx` / `dashboard.tsx` | 最简启动与降级 / 中文交互界面 |
| `widget.tsx` | 独立的桌面小组件入口，无 hooks、无蓝牙扫描 |
| `model.ts` / `copy.ts` | 数据模型、默认设置 / 中文文案与格式化 |
| `store.ts` / `diagnostics.ts` | 全局 Storage 持久化及校验 / 日志与中文诊断 |
| `battery.ts` / `snapshot.ts` | 实时本机电量 / 缓存去重、占位、排序与过期处理 |
| `bluetooth.ts` / `capabilities.ts` | 标准电池服务读取 / PRO 检测 |
| `audio.ts` / `async.ts` | 主动查询当前耳机输出 / 有界异步操作 |
| `theme.ts` / `ui.tsx` / `grid.tsx` | 自适应颜色 / 圆环单元 / 小组件尺寸布局 |
| `app_intents.tsx` | 显式触发的配件刷新 Intent |
| `script.json` | 中文项目清单与版本 |

[`installers/battery-widget.tsx`](../installers/battery-widget.tsx) 仍提供可选安装器，完整下载 **18 个运行文件** 后才写入。
安装器默认读取 `main` 中的同一功能目录。
推荐直接使用上方远程导入地址。

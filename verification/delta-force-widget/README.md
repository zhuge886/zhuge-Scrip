# 三角洲收益检查

```sh
sh fetch-types.sh
npm ci --ignore-scripts
npm run check
```

固定 TypeScript 版本及宿主声明镜像；类型目录和 node_modules 不提交。smoke.cjs 用合成数据模拟网络、钥匙串和 WebView，执行 24 项检查，覆盖最近日报、休息日缓存与迁移、扫码生命周期、身份隔离及无余额时的小组件展示。

类型和虚拟节点检查不能替代 iPhone 的真实扫码、原生布局与桌面刷新验证。完整范围见 [验证记录](../../delta-force-widget/VERIFICATION.md)。

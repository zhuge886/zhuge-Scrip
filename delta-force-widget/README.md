# 三角洲收益 · Scripting 1.1.0

iPhone Scripting 项目，展示本人昨日收益和总哈夫币余额，支持微信授权、官网同步、小号 / 中号桌面组件、缓存与脱敏诊断，无需服务器。

## 导入或更新

在 Scripting → 导入远程脚本中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/delta-force-widget
```

确认名称“三角洲收益”、版本 **1.1.0**。旧版若未保存登录，需要重新扫码。先在官方微信小程序确认本人角色能正常查询。

## 扫码成功但没有数据

1. 运行新版重新扫码。腾讯 SDK 确认授权后即保存登录，不再以余额查询成功作为保存条件；账号状态与各接口结果分别展示。
2. 点击“刷新收益与余额”。新版按照腾讯当前官网配置使用游戏专属域名，补齐身份映射参数。
3. 点击“通过官网同步数据 / 确认游戏角色”，在腾讯官方战绩页确认本人账号、大区和角色。官网提示绑定时由本人操作；点击“完成”后脚本通过官网 Milo SDK 查询并缓存余额、日报。
4. 仍失败时点击“复制脱敏诊断”。只需反馈这份报告，它不包含账号标识、Cookie、token、金额或原始响应。
5. 若小程序能查而官网不能查，可选择下文“导入本人小程序查询凭据”。不同应用的身份作用域和权限可能不同，不要自行替换 App ID 或 OpenID。

“检查当前查询身份的角色绑定”只查询，不自动修改。小程序已绑定，不保证官网当前查询身份也已绑定。

## 微信登录

**扫码：** 点击“微信扫码登录 / 更换账号”，将腾讯二维码显示在另一台设备，用本人微信扫一扫确认。SDK 成功回调后保存本机登录，再查询数据。等待最多 3 分钟，关闭页面即取消。

**本机授权：**

1. 点击“复制本机微信授权链接”，发到微信文件传输助手，在微信中打开并授权。
2. 腾讯中转页可能提示“s_url不在合法地址范围内”，这是保留一次性授权码的中间步骤，不代表脚本已登录。复制该页完整链接。
3. 回到脚本，点击“粘贴授权链接完成登录”。脚本校验 state、域名、应用 ID 和时效，再由官网 SDK 完成授权。

在 10 分钟内完成；微信授权码另有自身时效，过期或使用过须重新开始。返回链接只粘贴到本人手机脚本，不发给他人。

## 导入本人小程序查询凭据

这是可选的本机接入方式。**不要把原始 Cookie、完整请求或 token 发到聊天、Issue 或 GitHub。**

1. 用本人已配置的网络调试工具，例如 Stream、Surge 或 Charles，记录自己手机访问官方小程序的请求。
2. 刷新小程序收益 / 余额，找到 dfm.ams.game.qq.com/ide/ 或 comm.ams.game.qq.com/ide/ 上**成功返回本人数据**的请求。
3. 在脚本点“导入本人小程序查询凭据”，粘贴该请求的 Cookie、POST 表单，或包含 openid、access_token、appid、acctype 的 JSON。acctype 支持 wx / mini，App ID 必须保持原样。
4. 脚本仅在本机提取四字段并写入 Keychain，丢弃其余输入，再查询数据。导入成功不等于接口已接受授权，以指标结果为准。

若工具看不到有效请求，或请求不使用这四字段，此入口不能直接接入。Scripting 不能直接读取微信私有目录或自动取得小程序会话。凭据失效须本人重新获取。

## 桌面与数据口径

长按桌面 → 添加 Scripting 小组件 → 编辑小组件 → 选择“三角洲收益”。

- **昨日收益：** 只在 recentGainDate 等于北京时间昨日时显示 recentGain。最近日报较旧时，昨日金额显示 --，应用内说明最近日期及收益。例如 10 月 23 日看到小程序“近日收益（10.21）”，不能当成 10.22 的昨日收益。
- **总哈夫币：** 当前哈夫币余额 totalMoney，不含三角币、三角券或仓库估值。
- **刷新：** 建议每 30 分钟，实际由 iOS 调度。官网同步也写入桌面缓存，后台查询失败时标记缓存；应用内保留原查询时间，跨日不改标旧收益。
- **退出 / 换号：** 成功换号清除旧缓存；退出清除本机凭据、缓存、待授权状态及诊断。

## 隐私与验证范围

凭据只存本机 Keychain；普通存储仅含金额、日期、状态和脱敏诊断。请求直达腾讯，没有作者后端。脚本不操作游戏、买卖物品或领取奖励。

已通过严格类型检查及 **21 项模拟回归**，并核对腾讯当前公开配置。**开发环境没有 iPhone 或用户微信会话，1.1.0 仍需本人真机验证。** 建议按“刷新 → 官网同步 → 复制诊断”排查。

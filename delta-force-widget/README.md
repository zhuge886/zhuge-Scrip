# 三角洲收益 · Scripting 1.6.0

参考股市小组件：浅灰白卡片、黑灰文字，**盈利红、亏损绿**。金额和曲线采用相同的收益颜色，线下面是很浅的同色渐变。没有大面积蓝底，不显示游戏名和币种文字。

## 更新与原生预览

在 **Scripting → 导入远程脚本** 中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/delta-force-widget
```

覆盖更新现有项目，确认版本 **1.6.0**。登录、自动续期和已保存的历史保留。

运行后，“预览桌面组件”副标题应显示 **原生小号预览 · 1.6.0**。此按钮调用 Scripting 自身的 Widget.preview，运行实际桌面入口。若预览已更新而桌面还是旧样式：长按桌面组件 → 编辑 → 重新选择更新后的脚本；必要时只移除桌面旧组件再添加。

## 界面

- 普通组件底板为白色到极浅灰，采用内容层绘制；透明需要在 Parameter 中填 `transparent`。
- 正收益红色、负收益绿色、零收益黑灰色。曲线跟随最近收益颜色，坐标轴和数值标签隐藏。
- 只有一天记录时显示紧凑金额卡、实际日期和记录天数，收起曲线区域；有两天及以上时显示平滑走势，只有末端一个点。
- 小号 / 中号均支持。余额可用时显示，查询不到时隐藏。
- 应用内也改为白灰卡片。蓝色仅用于主要操作按钮，扫码、刷新、退出及原生预览保留。

## 近7天历史

每次查询成功后，按腾讯返回的**收益日期**保存日报。保留北京时间今天及前6天，同日更新覆盖，不重复累计；缺失日期不补零，实际零收益和负收益正常保存。

历史由本机查询累计，升级前未保存的日期无法补回。旧版现有的有效日报会成为一个历史记录。收益日超过7天后不再进入曲线，最近一期金额仍保留原日期。

同一账号重新扫码和自动续期保留历史；换号或退出清除。桌面与应用并发刷新会合并记录。

## 登录与刷新

首次使用微信扫码。1.3.0 及以后已启用续期的账号无需为了更新再次扫码；更早版本需要扫码补存 refresh_token。访问凭据接近过期或日报鉴权失败时尝试续期，成功后重试一次。

续期目标是在约30天授权窗口内减少扫码，不能修改微信 / 腾讯端有效期或保证整月免登录。服务端撤销、风控、续期凭据缺失或到期仍需重新扫码。

建议桌面每30分钟刷新，实际由 iOS 调度。金额采用腾讯最近日报口径，并非最后一局收益。

## 验证

55 项模拟检查与严格类型检查通过，包含实际 widget.tsx 入口执行、独立内容底板、收益红绿配色、文字对比度及原生预览调用。云端没有 iPhone，最终显示请用应用内原生预览核对。

请求直达腾讯 / 微信，登录仅存本机 Keychain，缓存仅保存金额、日期和状态，无作者后端。

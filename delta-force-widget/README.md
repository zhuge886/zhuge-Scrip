# 三角洲收益 · Scripting 1.2.0

查看本人最近一份游戏日报的收益与日期。支持微信扫码、小号 / 中号桌面组件及离线缓存，无需服务器。

## 导入或更新

在 **Scripting → 导入远程脚本** 中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/delta-force-widget
```

确认名称“三角洲收益”、版本 **1.2.0**，更新现有项目。保留原项目可继续使用已保存的微信登录和缓存；不要先退出或删除旧项目。

## 使用

1. 首次使用点击“微信扫码”，将腾讯登录二维码显示在另一台设备上，用本人微信扫一扫并确认。授权后自动返回并刷新。
2. 已登录时点击“刷新收益”即可。“更换账号”重新扫码；退出会清除本机登录和缓存。
3. 添加桌面组件：长按桌面 → 添加 Scripting 小组件 → 编辑小组件 → 选择“三角洲收益”。

当前仅保留扫码登录、刷新和退出。已移除链接授权、官网同步、角色检查、凭据导入及诊断入口。

## 展示口径

- **最近收益：** 使用腾讯日报的 recentGain 和实际 recentGainDate。例如 10 月 23 日最新日报为 10 月 21 日，则主金额直接显示这份收益，旁边标注 **2026.10.21**。休息日不再显示“昨日 --”。
- **日报与单局：** 这是最近一个有记录日期的日报收益，采用腾讯的统计口径，并非最后一场对局收益，也不保证等于余额差。
- **总哈夫币：** 仅在本次有效查询成功时显示余额，获取不到或仅有旧余额缓存时隐藏整行，小组件保留收益和日期。余额 0 是有效值。
- **缓存：** 断网或登录过期仍保留最近收益及其日期，底部标明“上次同步”；更新日期不会冒充收益日期。新数据到达后替换，同一天的修正也会更新。
- **刷新：** 应用内可手动刷新；桌面建议每 30 分钟更新，实际时机由 iOS 决定。数据日期也受腾讯日报发布进度影响。

1.1.0 将休息日前最近日报写在提示语中的缓存，会自动恢复为新版的主金额。换号后不混用旧账号收益。

## 隐私与验证

登录保存在本机 Keychain，普通缓存保存金额、日期及状态。请求直接发送到腾讯，无作者后端。

用户已确认扫码登录与最近一期收益可用。1.2.0 已通过严格类型检查及 **24 项模拟测试**；新版原生界面、桌面布局和真实刷新仍需在 iPhone 验证。

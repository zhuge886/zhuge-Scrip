# 三角洲收益 · Scripting 1.7.0

按最新效果图重做小号和中号桌面组件：冷白 / 浅灰蓝底板、克制的原生材质、细高光边缘，盈利红、亏损绿、零收益灰。中号左右分栏，小号独立纵向排版，不显示游戏名和币种文字。

## 安装与更新

在 **Scripting → 导入远程脚本** 中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/delta-force-widget
```

覆盖原项目，确认版本 **1.7.0**，再运行“刷新收益”。导入整个功能目录，包含新增的 `presentation.ts` 和 `trend-view.tsx`。原 Keychain、缓存键和数据格式不变；同账号登录、续期和历史保留。

应用内提供“预览小号组件”和“预览中号组件”，调用 **Widget.preview** 运行实际桌面入口，可选择四种主题；小号按钮下显示“原生预览 · 1.7.0”。桌面仍为旧样式时，长按组件 → 编辑 → 重新选择更新后的脚本，必要时只移除桌面旧组件再添加。

## 布局与数据

- 中号左侧：收益图标、7日收益、有效记录天数和涨跌统计、最新单日金额及日期；右侧：记录数量、累计曲线、每日盈亏柱、精简日期。
- 小号：标题与数量、涨跌统计、简化图表、最近收益日期、最新单日金额。长金额降低字号并启用单行缩放，保持完整整数。
- 大字始终是**最近一期单日收益**；折线是窗口内已记录日报的**累计收益**，两者不混用。
- 正收益使曲线上升、负收益使曲线下降、零收益保持水平。折线段和每日柱按当天正负分别使用红 / 绿 / 灰；转折点保留小圆点，末点略大，填充极淡。
- 例如真实记录为 +50,000、−20,000、+80,000，统计为 2涨1跌，累计为 50,000 → 30,000 → 110,000；大字仍为 +80,000。
- 起笔位置是累计计算的零原点，没有日期、记录数或柱形，不是补造的一天。单条记录展示从零原点到该日报的变化，零收益为水平线。
- 无近7日记录时显示空状态，仍保留缓存的最近金额及原日期；没有有效余额则不显示余额行。

每次查询成功后，按腾讯返回的**收益日期**保存日报。范围为北京时间今天及前6个自然日：同日修正覆盖，缺失日期不补零，日期间隔真实保留。历史由本机查询积累，无法补回从未保存的日报。

## 主题

小组件 Parameter 支持以下文本，也支持 JSON：

| 主题 | 文本参数 | JSON |
| --- | --- | --- |
| 跟随系统（默认） | `system` 或留空 | `{"theme":"system"}` |
| 浅色 | `light` | `{"theme":"light"}` |
| 深色 | `dark` | `{"theme":"dark"}` |
| 透明 | `transparent` | `{"background":"transparent"}` |

兼容旧 `{"background":"stock"}`；显式透明时不绘制底板或边框，文字与图表仍适配系统明暗。脚本参数不能代替 Scripting 宿主自身的透明组件设置。

背景使用原生 `regularMaterial`、低对比度渐变、0.65 点高光描边和柔和阴影；深色避免白色发光边缘。材质只能模糊宿主提供的内容，**不承诺系统级桌面壁纸模糊或折射**。宿主没有相应效果时，内容层冷白 / 深灰底板仍可显示。

当前无需 PNG、远程图片或素材下载，离线不受 GitHub 图片加载影响。图表使用原生 Canvas 动态绘制；缺少 Canvas 的旧宿主回退到原生累计折线与每日柱形图。没有截图模拟玻璃效果。

## 登录与刷新

首次用本人微信扫码。已有续期凭据的账号无需为了更新再次扫码。访问凭据接近过期或日报鉴权失败时尝试续期，成功后重试一次；同账号重新扫码、自动续期保留历史，换号或退出清除。

续期采用约30天固定授权窗口，不能修改微信 / 腾讯的有效期或保证整月免登录。服务端撤销、风控、续期凭据缺失或到期仍需重新扫码。

建议每30分钟刷新，实际由 iOS 调度。请求直达腾讯 / 微信，凭据只存本机 Keychain，无作者后端。数据是最近日报口径，并非最后一局收益。

## 界面

- 桌面只保留近7天走势、最近收益、日期，以及可用时的余额。不显示游戏名和币种文字。
- 细蓝线使用平滑的单调插值，配浅蓝渐变；只在末端保留一个点，折线上不标金额。
- 正收益为蓝色，负收益为柔和红色。蓝底 / 透明模式继续适配，透明模式不画卡片底板。
- 应用内采用白色页面、浅天蓝收益主卡、独立趋势区和一个主要刷新按钮；扫码、更换账号和桌面说明保留为简洁入口。

## 近7天收益折线

- 每次查询成功后，按腾讯返回的**收益日期**保存日报；不使用查询当天代替收益日期。
- 保留北京时间今天及前6天的记录，最多每天一条。同一天重新查询覆盖该点，不重复累加金额。
- 仅连接有记录的日期；没有记录的日期不补零。实际记录为零或负收益时正常保留。
- 线条上不显示金额、坐标数字或数值标签；最新一次收益的完整金额与日期放在线条下方。
- 只有一天记录时显示一个点，有两天及以上时连线。近7天没有记录时显示简短提示，下方仍可保留更早的最近一次收益。
- 历史由本机查询累计，**升级前未保存的日期无法补回**。升级会把现有缓存中的最近一天加入历史。
- 同一账号重新扫码或自动续期保留历史；更换账号或退出会清除。桌面和应用同时刷新时合并保存，避免丢失日期。

## 透明桌面组件

直接更新现有普通 Scripting 组件即可使用浅天蓝渐变底色。需要透明效果时：长按桌面 → 添加小组件 → Scripting → 选择 **“透明背景小组件”** → 编辑并选择“三角洲收益”。支持小号与中号，点按可打开脚本。

普通组件使用与主卡一致的浅天蓝渐变底，配加深的文字与金额颜色；透明类型则透出壁纸或系统底衬。脚本没有强制更改系统组件类型的 API。旧版系统或宿主没有该类型时，可用 Scripting 提供的“用图片模拟透明背景”，按宿主提示裁剪主屏幕截图。

**最近收益**文案为深色，正收益为蓝色、负收益为柔和红色，零收益为深色。收益日期紧邻“最近收益”，移除品牌名和币种标签，保留核心信息。渐变两端的文字对比度均通过 4.5:1 检查。

原生透明、模糊与图片模拟透明都会省略蓝色底板；文字和收益色随浅色 / 深色外观调整。任意壁纸的具体亮暗仍会影响可读性，蓝底样式提供稳定对比。登录与刷新状态在应用内查看。

## 登录与续期

- 仅保留微信扫码、刷新和退出。二维码显示在另一台设备上，用本人微信扫一扫并确认。
- 新登录保存 access_token、refresh_token 和有效时间到本机 Keychain。普通缓存不保存这些凭据。
- 得知访问凭据即将过期时提前续期；日报接口提示失效时，自动续期后重试一次。余额单独失败不会触发反复登录。
- 采用微信 OAuth 的续期方式，目标是在约 30 天授权窗口内减少扫码。续期不会把窗口无限顺延；服务端撤销授权、风控、缺少续期凭据或授权到期仍需扫码。
- **不能保证整月免登录。** 本机原本已长期保存登录，真正限制来自微信 / 腾讯端。桌面后台也由 iOS 调度，脚本不能保证持续运行。
- 续期暂时断网时保留登录及最近收益；只有确认鉴权失效才在应用内提示扫码。退出清除本机登录和缓存。

## 数据口径

显示腾讯日报的 recentGain 与实际 recentGainDate，属于最近有记录日期的日报收益，**并非最后一局收益**。休息日继续保留最近记录；日期不会改成今天。

零收益和负收益都是有效记录。断网后保留原金额与日期。余额仅在有效查询成功时显示，旧余额缓存不当作当前余额。建议每 30 分钟刷新，实际时机由 iOS 决定。

请求直达腾讯 / 微信，无作者后端。**52 项模拟测试和类型检查通过，透明模式与真实续期仍需 iPhone 验证。**

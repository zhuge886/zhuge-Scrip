# 三角洲收益 · Scripting 1.3.1

简洁查看本人最近一份游戏日报的收益与日期。普通桌面组件采用白底、深色文案与反差色金额；透明组件不绘制底板。没有图标或登录横幅。余额可用时显示，无法获取时隐藏。

## 更新

在 **Scripting → 导入远程脚本** 中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/delta-force-widget
```

确认版本 **1.3.1**，更新现有项目。保留原登录与收益缓存。

1.3.0 已扫码启用续期的账号无需再扫码。只有 1.2.x 及更早版本需要重新扫码一次，补存原先缺失的 refresh_token。

## 透明桌面组件

直接更新现有普通 Scripting 组件即可使用白底样式。需要透明效果时：长按桌面 → 添加小组件 → Scripting → 选择 **“透明背景小组件”** → 编辑并选择“三角洲收益”。支持小号与中号，点按可打开脚本。

普通组件使用白底，确保文案始终可读；透明类型则透出壁纸或系统底衬。脚本没有强制更改系统组件类型的 API。旧版系统或宿主没有该类型时，可用 Scripting 提供的“用图片模拟透明背景”，按宿主提示裁剪主屏幕截图。

**最近收益**文案为深色，正收益为深绿、负收益为深红，零收益为深色。收益日期紧邻“最近收益”，单位单独标明“哈夫币”。白底上的所有文字均通过 4.5:1 对比度检查，避免白字白底。

原生透明、模糊与图片模拟透明都会省略白底；文字和收益色随浅色 / 深色外观调整。任意壁纸的具体亮暗仍会影响可读性，白底样式提供固定对比。登录与刷新状态在应用内查看。

## 登录与续期

- 仅保留微信扫码、刷新和退出。二维码显示在另一台设备上，用本人微信扫一扫并确认。
- 新登录保存 access_token、refresh_token 和有效时间到本机 Keychain。普通缓存不保存这些凭据。
- 得知访问凭据即将过期时提前续期；日报接口提示失效时，自动续期后重试一次。余额单独失败不会触发反复登录。
- 采用微信 OAuth 的续期方式，目标是在约 30 天授权窗口内减少扫码。续期不会把窗口无限顺延；服务端撤销授权、风控、缺少续期凭据或授权到期仍需扫码。
- **不能保证整月免登录。** 本机原本已长期保存登录，真正限制来自微信 / 腾讯端。桌面后台也由 iOS 调度，脚本不能保证持续运行。
- 续期暂时断网时保留登录及最近收益；只有确认鉴权失效才在应用内提示扫码。退出清除本机登录和缓存。

## 数据口径

显示腾讯日报的 recentGain 与实际 recentGainDate，属于最近有记录日期的日报收益，**并非最后一局收益**。休息日继续保留最近记录；日期不会改成今天。

零收益和负收益都是有效记录。断网后保留原金额与日期。余额仅在有效查询成功时显示，旧余额缓存不当作当前余额。建议每 30 分钟刷新，实际时机由 iOS 决定。

请求直达腾讯 / 微信，无作者后端。**40 项模拟测试和类型检查通过，透明模式与真实续期仍需 iPhone 验证。**

# 三角洲收益 · Scripting 1.5.2

组件直接绘制天蓝渐变底板：记录不足2天时显示紧凑的收益与日期，有2天及以上记录时显示细蓝曲线。应用内提供 Scripting 原生小号组件预览。

## 更新

在 **Scripting → 导入远程脚本** 中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/delta-force-widget
```

确认版本 **1.5.2**，覆盖更新现有项目，保留原登录与收益缓存。

运行后，“预览桌面组件”副标题应显示 **原生小号预览 · 1.5.2**。点它可通过 Scripting 自身预览桌面入口；这不是浏览器布局预览。

若预览已更新而桌面仍是白底“近7天”：长按桌面组件 → 编辑小组件 → 重新选择本次更新的“三角洲收益”。必要时只移除桌面旧组件再添加，保留脚本项目。

1.3.0 已扫码启用续期的账号无需再扫码。只有 1.2.x 及更早版本需要重新扫码一次，补存原先缺失的 refresh_token。

## 界面

- 桌面只保留近7天走势、最近收益、日期，以及可用时的余额。不显示游戏名和币种文字。
- 两天以上记录使用平滑细蓝线和浅蓝渐变，只在末端保留一个点，折线上不标金额。只有一天时收起图表，显示金额、日期与记录天数。
- 正收益为蓝色，负收益为柔和红色。默认明确绘制蓝底；透明需要在组件参数中填 transparent。
- 应用内采用白色页面、浅天蓝收益主卡、独立趋势区和一个主要刷新按钮；扫码、更换账号和桌面说明保留为简洁入口。

## 近7天收益折线

- 每次查询成功后，按腾讯返回的**收益日期**保存日报；不使用查询当天代替收益日期。
- 保留北京时间今天及前6天的记录，最多每天一条。同一天重新查询覆盖该点，不重复累加金额。
- 仅连接有记录的日期；没有记录的日期不补零。实际记录为零或负收益时正常保留。
- 线条上不显示金额、坐标数字或数值标签；最新一次收益的完整金额与日期放在线条下方。
- 少于两天记录时收起图表，显示紧凑金额卡和记录天数。更早的最近金额仍保留其原日期；多日数据才形成曲线。
- 历史由本机查询累计，**升级前未保存的日期无法补回**。升级会把现有缓存中的最近一天加入历史。
- 同一账号重新扫码或自动续期保留历史；更换账号或退出会清除。桌面和应用同时刷新时合并保存，避免丢失日期。

## 蓝色底板与透明

普通组件默认直接绘蓝色底板。除了宿主背景属性，独立桌面视图还有一个普通 Rectangle 渐变图层，并按 Widget.displaySize 填充；不只依赖可能被宿主跳过的 widgetBackground。

需要透明时，在小组件参数（Parameter）中填写 `transparent`，并按宿主要求选择透明类型或图片模拟透明。默认蓝底不再根据宿主透明 / 模糊标志自动关闭。

桌面左上角新版文字为 **“7日收益”**，右上角显示记录天数；原来的白底“近7天＋孤立圆点”不再是新版单日布局。

## 登录与续期

- 仅保留微信扫码、刷新和退出。二维码显示在另一台设备上，用本人微信扫一扫并确认。
- 新登录保存 access_token、refresh_token 和有效时间到本机 Keychain。普通缓存不保存这些凭据。
- 得知访问凭据即将过期时提前续期；日报接口提示失效时，自动续期后重试一次。余额单独失败不会触发反复登录。
- 采用微信 OAuth 的续期方式，目标是在约 30 天授权窗口内减少扫码。续期不会把窗口无限顺延；服务端撤销授权、风控、缺少续期凭据或授权到期仍需扫码。
- **不能保证整月免登录。** 本机原本已长期保存登录，真正限制来自微信 / 腾讯端。桌面后台也由 iOS 调度，脚本不能保证持续运行。
- 续期暂时断网时保留登录及最近收益；只有确认鉴权失效才在应用内提示扫码。退出清除本机登录和缓存。

## 数据口径

显示腾讯日报的 recentGain 与实际 recentGainDate，属于最近有记录日期的日报收益，**并非最后一局收益**。休息日继续保留最近记录；日期不会改成今天。

零收益和负收益都是有效记录。断网后保留原金额与日期。余额仅在有效查询成功时显示，旧余额缓存不当作当前余额。建议每 30 分钟刷新，实际时机由 iOS 决定。

请求直达腾讯 / 微信，无作者后端。**55 项模拟测试和类型检查通过，透明模式与真实续期仍需 iPhone 验证。**

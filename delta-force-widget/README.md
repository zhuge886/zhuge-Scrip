# 三角洲收益 · Scripting

iPhone **Scripting** 项目，显示本人《三角洲行动》**昨日收益**与**总哈夫币（当前余额）**。支持小号和中号桌面小组件、微信扫码登录、本机微信授权、失败缓存和退出清理。

这是 Scripting 的 TypeScript / TSX 项目。入口为 `index.tsx` 与 `widget.tsx`，无需部署服务器。

## 导入

在最新版 **Scripting → 导入远程脚本** 中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/delta-force-widget
```

名称为 **三角洲收益**，版本 **1.0.0**。首次运行时允许网络、存储和钥匙串权限。请先在腾讯官方“三角洲行动”小程序中登录本人微信账号、确认角色能够正常查询。

## 微信登录

两种方式任选一种；无需向作者提供 Cookie 或微信密码。

### 本机微信授权（同一部 iPhone）

1. 运行脚本，点 **复制本机微信授权链接**。
2. 把链接发送到微信文件传输助手，在微信中打开并完成授权。
3. 授权后会停留在腾讯中转页，可能出现 **“s_url不在合法地址范围内”** 提示。这是保留一次性授权码的中间步骤，不代表脚本已经登录成功。请在微信右上角复制此时页面的**完整链接**。
4. 回到脚本，点 **粘贴授权链接完成登录**，粘贴刚复制的链接。
5. 脚本核对本次授权的 `state`、应用 ID 和时效，再由腾讯官网的 Milo SDK 完成授权。查询到本人哈夫币数据后才保存凭据。

授权链接有效期按本地流程限制为 10 分钟。一次性授权码还受微信有效期限制；出现已使用或过期时，重新从第一步开始。返回链接包含一次性授权码，请只粘贴到自己手机的脚本。

### 微信扫码（有另一台设备）

点 **微信扫码登录 / 更换账号**，脚本在独立网页中打开腾讯官网的微信二维码。把二维码显示在另一台设备上，用本人微信扫一扫并确认。登录等待最多 3 分钟，查询成功后自动返回。关闭网页即取消。

脚本不会自动操作游戏、买卖物品或领取奖励。微信授权交互必须由本人完成；这不是原生微信 SDK 的“一键拉起微信”登录。

## 桌面组件

长按桌面 → 添加小组件 → Scripting → 选择小号或中号 → 编辑小组件 → 选择 **三角洲收益**。点击小组件打开脚本，可刷新、重新登录或退出。

- **昨日收益**：读取腾讯烽火地带日报的 `recentGain`，且仅当 `recentGainDate` 等于北京时间昨日时显示。没有昨日数据时显示 `--`，不会用旧日报或 `0` 冒充。
- **总哈夫币**：读取哈夫币当前余额 `totalMoney`，不包含三角币、三角券和仓库估值。
- **刷新**：建议每 30 分钟刷新，实际时间由 iOS 调度。应用内可手动刷新；小组件在 5 分钟内可复用成功缓存。
- **缓存**：失败时保留最近成功数据，并标记缓存。应用内显示每个指标的查询时间。北京时间跨日后不再显示前一天的收益缓存。
- **换号 / 退出**：成功换号清除旧账号缓存；退出移除本机登录凭据、缓存和待完成授权。

## 数据与隐私

凭据只写入 Scripting 的本机 Keychain，不写入项目文件、普通 Storage 或 GitHub。普通缓存只有金额、日期和状态。登录页面和接口请求直接访问腾讯域名，没有作者后端。微信二维码和 H5 授权使用腾讯官网现有 Milo SDK；SDK 由腾讯在线提供，可能随官网调整。

# 1.6.0 验证记录

## 已完成

- TypeScript 5.8.3 严格检查通过，使用固定提交的公开 Scripting 声明。
- **55 项模拟回归通过**。保留查询、续期、7天历史、缓存、并发及金额精度测试。
- 测试改为直接验证独立 WidgetCard；实际执行 widget.tsx 入口（模拟宿主和网络），核对 Widget.displaySize 固定尺寸、默认白灰底层与新版“7日收益”标题。
- 模拟旧透明标志开启时默认仍绘制卡片；移除 background / widgetBackground 修饰符后，内容树中仍保留渐变 Rectangle。
- 默认卡片需要显式参数才能转为透明，透明时省略根背景与 Rectangle；文字对白灰渐变端点保持至少 4.5:1 对比。
- 单日或零条历史收起 Chart，保留最近金额及原日期，不生成假曲线；有两天以上记录时仍显示无数值注释的平滑线。
- 核对应用预览调用的是 Widget.preview，并传入默认股市参数，不是浏览器截图。
- 收益颜色按最新参考图统一为盈利红、亏损绿；应用与组件共用颜色函数，测试覆盖正负值约定。

## 尚未验证

没有 iPhone 或 Scripting 原生运行环境，不能确认用户手机的最终绘制或旧组件绑定。模拟入口测试能验证代码路径，不等同于已经完成 WidgetKit 真机测试。

旧版浏览器布局预览没有验证背景在用户手机上是否实际生效。此次提供原生预览入口，把手机验收放到实际桌面渲染路径。

## 手机确认

1. 覆盖更新至 **1.6.0** 并运行；“预览桌面组件”副标题应为“原生小号预览 · 1.6.0”。
2. 点击原生预览，核对浅灰白底与红绿金额、新标题“7日收益”及记录天数。单条记录不应再出现大块空白和一个孤立圆点。
3. 若原生预览已更新但桌面仍旧：长按桌面组件 → 编辑 → 重新选择更新后的“三角洲收益”，必要时只移除桌面旧组件再添加。
4. 金额和日期继续来自真实日报。积累至少两天后出现曲线，缺失日期不补零。
5. 若需要透明，在 Parameter 填 transparent。原登录与7天历史保留。

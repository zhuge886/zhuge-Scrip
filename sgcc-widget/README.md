# 网上国网·手动户号（1.6.0）

在 iPhone Scripting 中查看电费余额。每个脚本独立存放，本目录包含入口、组件和全部运行依赖。

用户已确认 **1.5.2 能查询未绑定户号的余额**。1.6.0 沿用该查询方式，按参考图整理余额卡片与设置页。

## 这次更新

- 小组件采用白底、浅青色弧纹、国网标识和大号金额；支持随系统切换深色。
- 清楚标注“电费余额”“表内余额”或“应缴电费”。截止时间只显示到日期，避免小号底部被挤出；没有有效截止日期时标注查询更新时间。
- 成功查询余额不再提示“已获取部分数据”，也不再显示“未提供用电明细”。真正刷新失败时保留旧余额，组件显示“缓存”。
- 设置页先显示当前余额，再放户号、地区、刷新和预览。已配置的登录信息及查询诊断默认收起；原绑定户号和兼容入口放入“更多设置”。
- 已有账号、会话及匹配的成功缓存继续使用。打开设置立即显示本配置的最近查询结果，成功刷新后不弹确认框。

## 导入与使用

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/sgcc-widget
```

1. 更新后确认版本 **1.6.0**。
2. 填写完整户号，保留开头的0，选择所在地区。
3. 首次使用展开“登录账号”，填写自己的网上国网账号和密码。设备验证需要时发送并填写新的短信验证码。
4. 点“刷新余额”，然后点“预览小组件”。已配置过的账号可以直接刷新或预览。

余额、表内余额和应缴电费含义不同，以卡片标签为准。表内余额可能是服务端指定截止时间的数据。交费入口只提供金额，不请求日/月用电明细。

更多设置保留户号来源、查询入口、兼容公司/类型选择、缓存清除和诊断复制。原绑定/兼容入口可选择明细及图表样式。

## 缓存与异常

普通组件刷新使用四小时缓存，“刷新余额”主动更新。失败只回退同一配置的缓存，并显示错误；换户号、地区或登录账号不会混用金额。切换界面样式不清除已成功查询的资料。

成功时核对完整户号和地区，空值不显示为零元，真实零元正常显示。不创建订单、不付款、不绑定户号。小组件首次需在设置中成功查询一次。

## 验证

TypeScript 严格检查及 **100项离线检查通过**。检查包含日期显示、旧提示过滤、真实缓存错误标识、设置缓存隔离和刷新提示行为。

1.5.2 的实际余额成功来自用户手机确认；1.6.0 的新排版尚需使用应用内原生预览核对字体和边距。本环境没有渲染真实 iOS 截图。

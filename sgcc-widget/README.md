# 网上国网·手动户号（1.3.0）

在 Scripting 中查询电费余额和用电明细。基于 [Honye 的 SGCC](https://github.com/Honye/scripting-scripts/tree/main/scripts/SGCC) 改造，所有入口、组件和依赖都保存在本目录。

## 这次修复

1.2.0 允许供电单位留空，但真实服务端返回了 `orgNo不能为空`。仅更换住宅、店铺等场景不能解决这个错误。

1.3.0 增加**从国网官网获取供电单位**：缺少单位资料时停止空单位请求，进入官方网页读取本户的真实资料，保存后再查询余额。不会猜测单位或把会计单位代码当成供电单位。

## 获取资料并查询

1. 选择“手动户号”，填完整户号并选择房子所在地区。
2. 点击“从官网获取供电单位”。也可以直接点“自动识别并查询”，缺少单位时会转入官网。
3. 在打开的 **95598 官方网页**完成本人登录，通过查询或其他户号交费入口查询同一户号，然后点 WebView 右上角“完成”。
4. 脚本读取并核对该户号的单位资料，自动填入、保存。只点了独立获取按钮时，再点“自动识别并查询”。
5. 对照官方显示核对金额，成功后再添加桌面或锁屏组件。

官网的短信、图形或人机验证需要你在官方页面完成。脚本不自动执行绑定、支付，也不会将官网登录令牌复制到脚本存储。官网不返回资料或要求其他授权时会显示具体原因。

资料读取优先采用你在官网实际查询得到的响应；没有捕获到时，通过官网自身的查询接口再读取一次。读取失败不会继续发送缺少 `orgNo` 的余额请求。

## 类型和高级设置

用电类型可选自动、住宅、店铺、电动车、企事业、新能源。获取到实际类型时会采用返回值，未知时最多按五种场景尝试。预付费/后付费由服务端计费字段判断。

高级设置保留手动单位代码和自定义地区代码。普通用户用官网获取，无需自行找代码。成功组合按账号、户号和地区保存，切换户号会清除自动填入的旧资料，小组件只复用成功组合。

## 余额与缓存

余额独立查询；需要明细时先获取余额再补查，明细失败仍可展示本次有效余额并提示原因。空响应不视为零，真实零金额正常显示。后付费余额和本期应缴分别展示。

普通刷新使用四小时缓存，主动查询跳过间隔。失败只回退到相同账号、户号、地区和参数的缓存并显示旧时间及警告。绑定模式保留原有前六户查询；组件参数可用完整户号或从 0 开始的序号。

## 验证范围

类型检查和 **56 项离线模拟通过**。**官网在 iPhone 中的实际登录、资料读取，以及取得单位后的真实余额查询仍待真机验证。** 当前没有经过本人真实国网账号的端到端验收，不能将模拟通过视为线上查询已成功。

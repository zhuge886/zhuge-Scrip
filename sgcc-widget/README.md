# 网上国网·手动户号（1.2.0）

在 Scripting 中查询电费余额和用电明细。基于 [Honye 的 SGCC](https://github.com/Honye/scripting-scripts/tree/main/scripts/SGCC) 改造，每个脚本的入口、组件和依赖均在自己的目录。

## 导入新版

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/sgcc-widget
```

在 Scripting 中重新导入/更新这个目录，确认版本 **1.2.0**。旧版的三个内部代码输入框已改为地区选择、类型选择和可选高级设置。

## 租房户号怎么查

1. 选择“手动户号”，填写完整户号，保留开头的 0。
2. 在“所在地区”选择房子所在省份/供电区域。河北分国网河北和国网冀北；不要按注册手机号所在地选择。
3. “用电类型”保留“自动尝试（推荐）”；普通租房也可以直接选择“住宅”。
4. **供电单位代码不用填**。高级设置默认收起，没有实际资料就保持空白。
5. 填写你自己的网上国网手机号和密码。新设备要求短信时，发送并填入验证码。
6. 点击“自动识别并查询”。界面显示正在尝试的类型和失败原因；成功后显示金额并保存可用组合。
7. 对照官方 App 核对金额，再添加桌面/锁屏小组件。参数留空即可。

“用电类型”是住宅、店铺、电动车、企事业、新能源五类使用场景；预付费/后付费由服务端返回的计费字段判断，不需要手选。

## 自动尝试做了什么

- 只查询你输入的户号和选择的地区，不修改绑定关系。
- 优先尝试上次成功的类型，其余按住宅、店铺、电动车、企事业、新能源的顺序，**最多五次**；明确选择一种类型时只尝试一次。
- 只有无有效余额、类型不匹配或相关参数错误才继续，间隔 750 毫秒。遇到短信/验证码、登录、权限、限流、网络或供电单位必填错误立即停止。
- 供电单位留空时不发送该字段，不猜测或枚举单位代码。如果有效响应返回单位/类型资料，则保存它；否则只保存这次可用的请求组合。
- 返回可核对户号时检查是否匹配，拒绝其他户号和无法区分的多户响应。若单户响应没有可核对的户号，界面明确提示你核对官方金额。
- 小组件只复用已保存的组合，不自行轮试类型。初次请先在脚本中完成一次成功查询。

服务端可能忽略类型参数，所以“可用组合”不代表已经认证了户号的真实用电类别。选择项来源和接口说明见 [API.md](API.md)。

## 仍有的限制

**可留空表示脚本允许不填，不代表所有地区的服务器都允许省略供电单位。** 本版没有凭空生成这些资料，也没有接入并验证 App“为其他户号交费”的专用资料查询流程。如果服务器明确要求供电单位或绑定授权，换类型不能解决，界面会保留原因。

未使用真实账号完成线上验证，也没有完成 iPhone 原生运行验收。开发环境已通过类型检查和 **37 项离线模拟**，见 [VERIFICATION.md](VERIFICATION.md)。

## 余额、明细与缓存

“余额 / 待缴金额”独立查询；选择“余额与用电明细”时，先获取余额再补查明细，明细失败仍可展示本次有效余额。后付费余额与本期应缴分别显示。空响应不会视为零，真实零余额正常显示。

普通刷新使用四小时缓存；点击查询会强制更新。缓存和可用组合按登录账号、户号、地区、类型及查询范围隔离。失败只回退到相同配置的缓存，并显示旧时间及警告。修改密码或在高级设置清除组合后需重新查询。

保留“账号绑定户号”模式，最多查询前六户。组件参数可以填写完整户号或从 0 开始的序号，仅选择已查询数据。

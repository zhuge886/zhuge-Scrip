# 网上国网·手动户号（1.5.1）

在 Scripting 中显示电费金额和用电信息。基于 [Honye 的 SGCC](https://github.com/Honye/scripting-scripts/tree/main/scripts/SGCC) 改造，入口、组件和运行依赖均在本目录。

## 这次修改

1.5.0 会把没有 `data.common.repcd` 的服务端错误遮蔽成“未返回业务状态”。1.5.1 先检查网关/业务错误，显示实际状态码和说明，再校验成功金额结构。结构未知仍然失败，不放宽身份核对、不将缺失金额当作零。

新增“复制查询诊断”：失败后关闭提示框，在“数据”区域复制文本。诊断只记录版本、时间、固定字段的类型及短状态码，不包含请求、户号、手机号、验证码、凭证、金额、姓名或住址。

**未绑定户号的真实查询链路仍未打通。** 已核对的单户刷新请求来自官方 Android 3.2.3 SDK，但进一步发现 SDK 独立网关配置和会话请求头，现有 App 登录请求不能视为完整的交费 SDK 初始化。89项离线检查验证解析和诊断逻辑，不代表查询成功。

本轮用空户号、空登录凭证对两个有官方出处的网关各发一次只读请求，均收到 `101001`，且没有业务金额结构。这证明旧版会遮蔽此类错误，**不能认定截图中实际收到的就是这个错误码**，也不能证明调整网关即可查通。需要手机生成的脱敏诊断继续定位。

## 导入和使用

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/sgcc-widget
```

更新后确认版本 **1.5.1**，原有手机号、密码和设备登录资料沿用。

1. 户号来源选“手动户号”，填写完整户号并保留开头的 0。
2. 地区选户号实际所在省市，例如“北京”。查询入口选“自动（推荐）”或“其他户号交费”。此入口无需填写供电公司代码和用电类型。
3. 填自己的网上国网登录账号。设备验证需要时，使用新收到的短信验证码。
4. 点击“查询金额”。失败时关闭提示框，点“复制查询诊断”反馈文本；若成功，再与官方 App 对应项目核对金额及截至时间。

交费入口只查询金额，不返回日、月用电明细。界面按接口计费方式标注“电费余额”“表内余额”或“应缴电费”；应缴金额不能当作剩余余额。北京表内余额可能有截止时间，应以该时间为准。

遇到实名、验证或确认提示会停止，不把伴随返回的金额直接展示。户号、地区必须与响应完全一致；掩码户号、缺失金额不会保存，也不会显示为零元。真实零元正常显示。

## 兼容入口

“原余额接口（兼容）”保留北京15家已核实的公司目录，包括国网北京城区供电公司 `11401`，地区路由 `11102`。这些是官方公共目录代码，不是猜测值；其他省市暂无内置公司表。

此入口可按真实公司及五种场景有限尝试：最多20家公司、每轮30次、串行且间隔至少1秒，可停止。绑定、权限、登录、限流、身份不匹配等错误立即停止。**换公司或类型无法解除原接口的绑定要求。**

## 缓存与权限

普通刷新使用四小时缓存，“查询金额”跳过间隔。失败仅回退同一配置的旧缓存，并保留时间和错误。1.5.0 使旧缓存与旧成功组合失效；切换查询入口、账号、户号或地区不会混用金额。小组件先需在设置中成功查询一次，后台不轮试公司。

查询只调用交费模块的单户刷新接口，不创建支付订单、不付款、不绑定户号。成功返回的查询标识仅在本地保存，以便刷新；不记录接口完整响应、姓名或住址。

# 网上国网·手动户号（1.1.0）

基于 [Honye 的 SGCC 小组件](https://github.com/Honye/scripting-scripts/tree/main/scripts/SGCC) 改造，新增手动户号来源、余额独立查询、App 内结果显示及按户号隔离的缓存。

## 当前功能

- 使用自己的网上国网手机号和密码登录，必要时完成新设备短信验证。
- 手动指定户号，不再因绑定列表为空而在本地停止；保留原来的绑定户号模式。
- 余额模式只请求余额接口。完整模式的日/月明细失败时，仍可显示有效余额并提示失败项。
- 支持 App 内查询结果和桌面/锁屏组件。未返回的明细不显示为零，后付费账户余额与本期应缴金额分别显示。
- 小组件参数支持完整户号或从 0 开始的序号；手动模式留空即可。

## 未绑定户号的限制

**当前不是“只输入户号就能查询”的已验证版本。**

手动户号不在登录返回的绑定列表时，原协议还需要以下资料：

| 设置项 | 实际查询资料中的字段 |
| --- | --- |
| 完整户号 | `consNo_dst` / `powerUserNo_dst`，保留开头的 0 |
| 省份代码 | `proNo` / `provinceId` |
| 供电单位代码 | `orgNo` |
| 用电类型代码 | `elecType` / `constType` |

这些值不能由户号前几位、行政区划代码或手机号猜测。匹配到已绑定户号时，脚本会使用服务端返回的完整资料，无需手填后三项。

**尚未接入并验证 App“为其他户号交费 / 输入户号查询”的专用资料查询接口。** 当前手动模式将明确填写的资料交给原 App 业务接口，能否查询未绑定户号由国网服务端决定，不能认定它等同于 App 的其他户号查询入口。

若需租房场景下仅填写户号，仍需确认省份、App 入口及该入口的实际请求和响应，再补充自动取得户号资料的适配器。离线模拟通过不表示线上查询成功。

## 导入与使用

在 Scripting 的“导入远程脚本”中粘贴：

```text
https://github.com/zhuge886/zhuge-Scrip/tree/main/sgcc-widget
```

1. 运行“网上国网·手动户号”，选择“手动户号（待验证）”。
2. 填写完整户号和实际取得的地区资料，先选择“余额 / 待缴金额”。资料未知时，当前版本无法自动补全。
3. 填写你自己的网上国网手机号和密码，不需要房东密码。手机号只用于取得会话，不用于选择户号。
4. 新设备需要短信时，发送并填写验证码，再点“立即刷新”。
5. 成功后在 App 核对户号末四位和金额，再添加小组件。

使用原有绑定户号功能时，改选“账号绑定户号”和“余额与用电明细”，最多查询前六户。组件参数只选择已查询的数据，不触发其他未配置户号的请求。

## 缓存与错误

正常请求使用四小时缓存，“立即刷新”跳过这个间隔。失败时只回退到同一登录账号、户号、地区资料与范围的旧缓存，并显示时间与警告。切换账号或户号时不会借用另一户的数据。

日/月明细无权限时可以展示已有余额；没有任何有效数据时明确报错。空响应不视为 `0.00`，服务端真实返回零余额则正常显示。

# 1.2.0 验证记录

## 已执行

- TypeScript 5.8.3 严格类型检查通过。
- **37 项离线模拟通过**，不请求生产国网接口，不读取任何真实账号或户号。
- 覆盖原有户号选择、缓存隔离、零值、明细降级及五种组件尺寸。
- 新增覆盖：供电单位/类型允许留空、最多五次、显式类型只尝试一次、成功即停止、真实零值成功、响应户号核对、多户歧义拒绝、返回资料学习、成功组合优先及组件单次复用。
- 验证短信/验证码、权限、登录、限流、网络和单位必填错误不会继续更换类型；未配置组合的小组件不会启动登录或试错。
- 验证切换户号、地区和请求期间配置变化不会借用另一户的组合或缓存。
- 从公开官网静态 JS 核实了地区路由与场景名称，参见 [API.md](API.md)。公开地区字典接口的直接请求返回 HTTP 405，因此没有把它包装成“已验证的自动资料获取接口”。

## 未验证

1. 原 App 登录与设备令牌协议当前的线上可用性。
2. 各省份原余额接口是否接受未绑定户号、是否允许省略供电单位。
3. 官网地区路由在 App 业务接口中的地区兼容情况。
4. iPhone Scripting 原生布局、首次短信与系统小组件刷新。
5. App“为其他户号交费”专用资料查询流程。本版仍没有接入该流程，不承诺补全服务端必需且未返回的资料。
